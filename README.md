# etolegko-test
Консольный скрипт на Python для замера скорости скачивания: выполняет N последовательных запросов к указанному URL, дожидается полного чтения тела каждого ответа и выводит среднее время запроса, общий объём скачанных данных и скорость скачивания.

## Требования
- Python 3.10 или выше
- Зависимости: `aiohttp` (устанавливается из `requirements.txt`)

## Установка
```bash
python3 -m venv .venv
.venv\Scripts\activate    # Windows
source .venv/bin/activate # macOS / Linux

pip install -r requirements.txt
```

## Запуск
```bash
python download.py <URL>
```

Опциональные аргументы:
- `--requests N` - количество последовательных запросов (по умолчанию: `10`)
- `--timeout SEC` - таймаут одного запроса в секундах (по умолчанию: `60`)

Пример:
```bash
python download.py https://example.com/large-image.jpg
python download.py https://example.com/large-image.jpg --requests 5 --timeout 30
```

## Что именно измеряется
- Время запроса - время от старта запроса до полного чтения тела ответа (wall-clock, time.perf_counter()).
- Среднее время запроса - сумма времён всех запросов, делённая на их количество.
- Общий объём - суммарное количество байт тела ответа, реально прочитанных из сети (не значение заголовка Content-Length).
- Скорость скачивания - общий объём / суммарное время, то есть средняя скорость за весь прогон.

## Единицы измерения
Скорость выводится в Кб/с и Мб/с, где:
- 1 Кб = 1024 Б
- 1 Мб = 1024^2 Б = 1 048 576 Б
Объём также форматируется в Кб / Мб / Гб по тому же принципу.

## Пример вывода
```
Запросов: 10
Всего байтов: 25.40 Мб
Всего времени: 12.345с
Среднее время запроса: 1.235с
Скорость загрузки: 2.06 Мб/с
```
Прогресс по каждому запросу печатается в stderr и не смешивается с итоговым отчётом в stdout.

## Обработка ошибок
- Сетевые ошибки и HTTP-статусы 4xx/5xx -> сообщение в stderr, код возврата 1.
- Превышение таймаута -> сообщение в stderr, код возврата 1.
- При успешном завершении -> код возврата 0.
